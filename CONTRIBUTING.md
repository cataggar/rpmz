# Contributing to rpmz

Contributions are welcome in the
[cataggar/rpmz repository](https://github.com/cataggar/rpmz). Search or open
[issues](https://github.com/cataggar/rpmz/issues), create a topic branch from
`main`, and submit a
[pull request](https://github.com/cataggar/rpmz/pulls) with logical commits.

Before opening a pull request, follow
[Building and testing](doc/building-and-testing.md). For implementation
conventions, see the [coding guidelines](doc/coding-guidelines.md).

Keep a branch current by rebasing it on `main`. Amend or squash fixups into the
commit that introduced the change; keep independently useful changes as
separate commits.
